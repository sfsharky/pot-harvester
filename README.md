# Pot Harvester

A simple GPS tool for spacing out pots (or any gear) by **distance** instead of time and speed.

Set the spacing and number of pots, press START, and the app counts down the distance to the next drop and sounds a horn when it's time. It uses the phone's GPS, so it works with no cell signal.

## What it does
- Counts down the distance to the next pot (feet, metres or yards) with speed and course over ground
- GRID mode: automatic alerts at your spacing
- ACTUAL mode: tap when the gear actually goes over and the spacing restarts from that spot
- HOLD / BYPASS: skip bad ground; the counter keeps running and you choose where the next pot goes
- Compass with N-UP and H-UP modes, day and night screens
- Spoken end marker reminder before the last pots
- Exports your pot positions as a GPX waypoint file for chart plotters and mapping software

## Install
**iPhone:** open https://potharvester420.netlify.app in Safari, tap Share, then Add to Home Screen.

**Android:** open the link in Chrome, tap the three dots, then Install app. Or download the `.apk` file from the Releases section of this page and open it.

Open it once with signal first so it saves itself for offline use, and tap Allow for location.
